# Synax 1.7.x Code Mode Implementation Plan

> **For agentic workers:** 使用 superpowers:executing-plans 在本会话按任务执行；用户已批准直接实施，不委派子代理。

**Goal:** 交付安全、轻量、默认关闭、可直接使用的只读 Code Mode。
**Architecture:** QuickJS WASM + 独立 Worker，通过 RPC 调用现有 ToolRegistry。复用设置、权限和工具事件，Direct Tool Calling 保留。
**Tech Stack:** Node 22、TypeScript、QuickJS 0.32.0、Vitest、既有 React/Headless UI。
**Spec:** docs/superpowers/specs/2026-10-03-code-mode-design.md

## Global Constraints

- 从 origin/HEAD 指向的生产 main 创建 feature/1.7.0-codemode，不合并 test/beta。
- .DS_Store 不纳入 Git；用 version:minor/sync 同步唯一版本源。
- 以 services/local-node、services/worker、client 为准，不使用旧 api/web 路径。
- 默认只读、项目 opt-in、进程 kill switch；不自动重试或自动授权。
